Smart Approval Workflow

Create configurable approval workflows for any Odoo document.

Replace approvals done over WhatsApp, email and phone calls with a structured, auditable process inside Odoo. Define multi-level approval flows for purchase orders, vendor bills, expenses, discounts, payments, inventory adjustments, refunds, HR requests, contracts — or any custom model — without writing code per client. Built for Odoo Community, no Enterprise required.

Any document, any rule

Point a workflow at any Odoo model and choose when it applies: always, above an amount threshold, or matching a domain. The amount field is picked from the model's own fields — no fragile typing.

Multi-level approvals

Sequence as many steps as you need. Each step routes to a specific user, a whole group, or the requester's manager, with a required number of approvals and optional rejection.

Full audit trail

Every approval and rejection is stored with the approver, date and comment. Chatter and scheduled activities keep everyone notified and accountable.

Lightweight & extensible

The core depends only on base and mail. Connect it to Purchase, Accounting, Sales, Inventory or HR with separate optional modules when you need them.

What's included

  • Configurable workflows for any model with always / amount / domain rules
  • Multi-level steps: specific user, group, or requester's manager
  • Submit → approve → reject lifecycle with reset and cancel
  • Approver activities, chatter, and a complete approval history
  • My Pending Approvals, My Requests, and status filters
  • User / Manager / Administrator security profiles with record rules
  • A clean integration API to auto-create approvals from other modules
